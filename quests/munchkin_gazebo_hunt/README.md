# Манчкин: Охота на Газебо

Автор: Lomiren  
Описание автора: Легендарная битва начинается там, где заканчивается здравый смысл.

## Идея

Легендарная битва начинается там, где заканчивается здравый смысл.

Кампания вдохновлена мемом из настольного Манчкина про паладина, который встретил Газебо и решил, что это явно не просто беседка.

Это квест о храбрости, сомнительных решениях и противнике, которому даже не нужно двигаться, чтобы победить.

Дойди до сада, разбуди легенду и попробуй уйти достаточно далеко, чтобы потом назвать это охотой.

Кампания считается завершенной после обязательного достижения «Разбудить Газебо окончательно». Два финальных достижения остаются необязательным эпилогом: огненный маг на потом и сверхдальний побег от Газебо.

## Важная заметка для PR

Название использует слово «Манчкин», поэтому maintainer может попросить переименовать кампанию для публичного приложения. Вторая легендарка «Охотник на Газебо» оформлена как `globalLegendaryAchievements` с привязкой к `categoryId`; это тоже стоит явно отметить на review.
